# 小玩意儿 Playroom

九款可以直接在浏览器游玩的轻量小游戏。纯静态站点，无需后端、数据库或第三方 API。

## 在线游玩

**https://klwjlalala.github.io/games/**

仓库已使用 GitHub Actions 部署 GitHub Pages。推送到 `main` 后会自动触发部署。

## 游戏列表

### 原有六款
1. **最后一车** — 空间装箱：旋转并摆放货物，填满车厢。
2. **拆迁队：最后一铲** — 爆破解谜：有限炸药清除建筑方块。
3. **茶汤有度** — 容量推理：在不同容量的杯子间倒水，达到目标水位。
4. **旧物修复所** — 清洁与配件匹配：擦去灰尘，安装正确零件。
5. **地底 100 层** — 反应挑战：切换轨道，躲避障碍并收集矿晶。
6. **玄岳背上的小森林** — 生态布局：安排地形，满足相邻与连通条件。

### 新增三款
7. **梦境拼接师** — 选择梦境题签，把物品拖入梦境空间；探索隐藏组合，生成可分享的梦境卡片。
8. **深夜便利店** — 接待三位深夜顾客，从货架挑选三件商品组成补给袋；不同选择会改变顾客的回应与最终夜班报告。
9. **宇宙售后服务中心** — 处理三张荒诞工单；调查现场的三个线索，再选择修复方案，查看宇宙客服值班评级。

## 本地运行

在项目目录执行：

```bash
python -m http.server 8080
```

然后访问 `http://localhost:8080`。

## 技术说明

- 原生 HTML / CSS / JavaScript，静态部署，无需构建步骤
- 不依赖外部图片、模型 API 或第三方运行时
- 游戏进度保存在浏览器 `localStorage`（原有游戏）
- 新增三款游戏使用本地状态，刷新后重新开始
- 桌面端支持鼠标操作，新增游戏也适配触屏点击


## 机制优先可玩性实验（2026-11）

直接访问 **https://klwjlalala.github.io/games/prototypes/** 可试玩两款独立原型：

- **十步突围**：7×7 棋盘、10 次行动、敌人下一回合攻击预告、冲刺与推击、三片封锁区及随机障碍。
- **背包守夜人**：5×4 背包装备空间、邻接联动、五夜自动战斗、三选一奖励、实时数值预览。

这两款原型用于验证机制与重玩动机，不代表经过真实玩家测试的正式成品。原有九款保持不变。
