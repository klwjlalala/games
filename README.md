# 小玩意儿 Playroom

六款可以直接在浏览器游玩的轻量小游戏原型。纯静态站点，无需后端、数据库或第三方 API。

## 在线游玩

启用 GitHub Pages 后访问：

**https://klwjlalala.github.io/games/**

仓库默认分支 `main` 的更新会通过 GitHub Actions 自动部署 Pages。

## 游戏列表

1. **最后一车** — 空间装箱：旋转并摆放货物，填满车厢。
2. **拆迁队：最后一铲** — 爆破解谜：有限炸药清除建筑方块。
3. **茶汤有度** — 容量推理：在不同容量的杯子间倒水，达到目标水位。
4. **旧物修复所** — 清洁与配件匹配：擦去灰尘，安装正确零件。
5. **地底 100 层** — 反应挑战：切换轨道，躲避障碍并收集矿晶。
6. **玄岳背上的小森林** — 生态布局：安排地形，满足相邻与连通条件。

## 本地运行

直接打开 `index.html` 即可。也可以启动任意静态文件服务器：

```bash
python -m http.server 8080
```

然后访问 `http://localhost:8080`。

## 技术说明

- 原生 HTML / CSS / JavaScript
- Canvas 仅用于爆破和矿井小游戏
- 游戏进度保存在浏览器 `localStorage`
- 无构建步骤、无外部运行时依赖

## 操作

- 桌面端：鼠标、键盘
- 手机端：触屏按钮与点击操作
- 游戏内的「重新开始」会重置当前关卡
